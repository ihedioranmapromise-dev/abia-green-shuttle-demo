# Abia Green Shuttle — Full interactive demo

Walkable prototype for the electric Green Shuttle programme.

## Screens

| Path | Purpose |
|------|---------|
| `/` | Landing |
| `/passenger` | Next bus, ETA, pay trip |
| `/track/[id]` | Live position on route |
| `/wallet` | Balance, top-up, pay, history |
| `/ops` | Fleet board + status |
| `/terminal` | At bay / next departure |
| `/report` | Incident → ticket ID |
| `/snapshot` | Day leadership strip |
| `/routes` | Corridors + fares |

## Run

```bash
npm i && npm run dev
```

Deploy on Vercel from this repo. Demo data only.
